# ✨ Liquid Glass Calculator

A modern, beautiful calculator with a **liquid glass** UI effect, smooth animations, and multiple color themes.

![Preview](https://via.placeholder.com/800x500?text=Liquid+Glass+Calculator)

## 🔥 Features

- Beautiful **Glassmorphism** design
- Floating animated background blobs
- Smooth button hover & active effects
- Calculation **History** panel with close button
- 3 Color Themes (Default, Cyan, Emerald)
- Keyboard support
- Fully responsive
- Created with ❤️ by [codewithrizi](https://github.com/codewithrizi)

## 🛠️ Technologies Used

- HTML5
- CSS3 (Glassmorphism + Animations)
- Vanilla JavaScript
